# Бензак — Война за бензак

Браузерная башенная защита в пустоши: кампания из 3 карт (Пустошь → Дюны → Руины города), 12 волн на каждой, 4 типа башен, 3 уровня улучшений, комбо между соседними башнями, 6 типов врагов и босс.
Написана на чистом JavaScript + [PixiJS](https://pixijs.com/), без сборщиков.

## Запуск

```bash
python3 -m http.server 8777
```

Открыть `http://localhost:8777/`. Играть удобно в портретном окне (телефон).

Один файл для передачи: `python3 build.py путь/Benzak.html` — всё встроено, открывается двойным кликом.

## Структура

- `index.html`, `game.js` — игра; `lib/pixi.min.js` — PixiJS
- `assets/` — спрайты (PNG, прозрачный фон); бриф и размеры — `ASSETS.md`
- `tools/` — вырезка фона и сборка спрайтов из сгенерированных картинок (Swift)
- `art/` — процедурный генератор запасного арта

## Карты и арт

- Карты описаны в `MAPS` в начале `game.js` (путь, площадки, множители сложности, свет).
- Арт карт: `assets/map.jpg`, `map_dunes.jpg`, `map_city.jpg` (1536×2560). Делаются так: `tools/guide.swift` рисует схему дороги и площадок,
  нейросеть перекрашивает схему, результат растягивается до 1536×2560.
- Спрайты: `tools/make_sprites.sh` (вырезка фона `tools/cutout.swift`).

## Геймплей

- **Башни:** пулемёт, огнемёт, шипомёт, генератор, тесла (цепная молния), миномёт (навесной огонь по площади); 3 уровня, на 3-м выбор пути A или B (см. `BR` в `game.js`).
- **Комбо:** соседние башни усиливают друг друга (6 пар), генератор усиливает комбо соседей.
- **Способности** (перезарядка идёт только во время волны): воздушный удар, ремонт всех башен, ЭМИ.
- **Превью волны:** перед стартом показан состав следующей волны.
- **Босс:** на 66% здоровья зовёт подмогу, на 33% впадает в ярость.
- **Враги:** багги, байкер, броневик, щитовик, штурмовик, дрон (летит напрямик, огнемёт/шипы/миномёт его не достают), лекарь, босс.
- **Звёзды** за карту (по оставшемуся топливу) и **11 достижений**.
- Арт веток 3-го уровня: `assets/<башня>_head3a.png` и `..._head3b.png` (если файла нет, берётся арт уровня).
