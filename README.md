# Бензак — Война за бензак

Браузерная башенная защита в пустоши: 10 волн, 4 типа башен, 3 уровня улучшений, комбо между соседними башнями.
Написана на чистом JavaScript + [PixiJS](https://pixijs.com/), без сборщиков.

## Запуск

```bash
python3 -m http.server 8777
```

Открыть `http://localhost:8777/`. Играть удобно в портретном окне (телефон).

Один файл для передачи: `python3 build.py путь/Benzak.html` — всё встроено, открывается двойным кликом.

## Структура

- `index.html`, `game.js` — игра; `lib/pixi.min.js` — PixiJS
- `assets/` — спрайты (PNG, прозрачный фон); бриф и размеры — `ASSETS.md`
- `tools/` — вырезка фона и сборка спрайтов из сгенерированных картинок (Swift)
- `art/` — процедурный генератор запасного арта
